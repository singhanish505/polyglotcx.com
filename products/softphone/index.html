The same security model as the rest of the platform

MFA & per-tenant SSO
TOTP multi-factor at sign-in and OIDC single sign-on per organisation. Short-lived tokens with silent refresh.
Credentials never leave the server
Trunk credentials are encrypted at rest and vended after auth — the app never keeps a reusable secret in the clear.
Data-residency aware
Inference and media route to the tenant region; an out-of-region write is refused, not silently allowed.
Role-based access
Agent, supervisor and admin scopes — the supervisor and field tools only appear for the roles that own them.
On-device secure storage
On mobile, session tokens live in the iOS Keychain / Android Keystore, not plain app storage.
Push that respects the lock screen
High-priority call pushes wake a locked device and bypass Do-Not-Disturb on Android; everything else is a normal notification.
